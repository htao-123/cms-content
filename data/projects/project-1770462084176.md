# Chatbot

一个功能完整的在线聊天应用，提供用户注册、登录和实时聊天功能。

## 📋 项目简介

Chatbot 是一个前端聊天应用项目，采用 HTML、CSS 和 JavaScript 技术构建。项目包含用户认证系统（登录和注册）以及完整的聊天界面，用户可以在注册和登录后进行实时消息交互。

## 🛠️ 技术栈

- **前端框架**: HTML5 + CSS3 + JavaScript
- **代码组成比例**:
  - JavaScript: 41.5%
  - CSS: 29.9%
  - HTML: 28.6%

## 📁 项目结构

```
Chatbot/
├── index.html          # 主聊天页面
├── login.html          # 用户登录页面
├── reg.html            # 用户注册页面
├── api.http            # API 接口文档
├── css/                # 样式文件夹
│   └── (CSS 样式表)
├── js/                 # JavaScript 脚本文件夹
│   └── (JavaScript 脚本)
└── asset/              # 资源文件夹
    └── (图片、图标等资源文件)
```

## ✨ 主要功能

- **用户注册** - 新用户可以创建账户
- **用户登录** - 已有账户的用户可以登录系统
- **实时聊天** - 登录后可以使用聊天功能进行消息交互
- **响应式设计** - 支持多种设备的访问

## 🚀 快速开始

1. 克隆或下载此项目
2. 在浏览器中打开 `index.html`、`login.html` 或 `reg.html` 文件
3. 根据需要进行注册、登录或聊天操作

## 📝 使用说明

### 首次使用
- 点击注册链接进入 `reg.html` 完成账户注册
- 输入用户名和密码完成注册流程

### 登录使用
- 进入 `login.html` 输入注册时的用户名和密码
- 成功登录后将跳转至聊天主页面 `index.html`

### 聊天功能
- 在主页面 `index.html` 输入消息并发送
- 与其他在线用户进行实时聊天交互

## 🔌 API 接口
